# Skills UI installés

Installés le 25 septembre 2026 à la demande du porteur depuis le registre [ui-skills.com](https://www.ui-skills.com/) (`npx ui-skills`). Le registre en ligne étant inaccessible depuis l'environnement de réalisation, les fichiers proviennent des dépôts sources référencés par ce registre, sous licence MIT :

| Skill | Source |
|---|---|
| ui-skills-root, improve-ui, fixing-accessibility, baseline-ui | github.com/ibelick/ui-skills (Julien Thibeaut) |
| swiftui-ui-patterns, swiftui-liquid-glass | github.com/dimillian/skills (Thomas Ricouard) |
| apple-design, write-swift | github.com/emilkowalski/skills (Emil Kowalski) |

`baseline-ui` et `fixing-accessibility` visent le web (React/Tailwind) : ils s'appliquent à `apps/web`. Le client Apple suit `swiftui-ui-patterns`, `swiftui-liquid-glass`, `apple-design` et `write-swift`, subordonnés aux décisions du dossier de conception (direction « Cartographie native », tokens 3.8).
