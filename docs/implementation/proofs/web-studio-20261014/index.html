Avant : interface Registre, produit 1c43c35, source de baseline 1b7d204. Après : interface Studio, produit e2f3673 ; les deux vues d’agenda ont été reprises après le correctif 2b4ca81. Les couleurs sombres Soft Charcoal et le cobalt Drivy sont conservés ; la composition, les contrôles, la navigation et la typographie sont revus.

Captures de composants React réels dans Microsoft Edge, avec BFF et personnes synthétiques en mémoire du test. Le menu ouvert a aussi été inspecté manuellement dans le navigateur avec CUA. Ces images ne constituent pas un test intégré OIDC/PostgreSQL ou une qualification d’accessibilité. Elles ne contiennent aucune donnée d’école réelle ni aucune capture Mercury.

Les huit paires desktop utilisent un viewport de 1440 pixels CSS ; les deux paires mobiles, 390 pixels CSS. Le menu ouvert est à 1280 pixels CSS. Les dimensions indiquées sous les titres sont celles des fichiers image complets. Le manifeste conserve les sources, les tailles et les empreintes SHA-256. Les menus, opérations et états non illustrés sont documentés dans les rapports de vérification séparés.
