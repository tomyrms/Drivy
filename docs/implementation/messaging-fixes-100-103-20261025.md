# Messagerie : correctifs #100 à #103 (25 octobre 2026)

Branche `claude/98-messagerie-refonte`, à la suite de #98.

## #102 Réactions

L'action d'une réaction lance une tâche détachée et rend la main tout de suite. Le menu et l'aperçu se ferment sans attendre le serveur. La requête part environ 350 ms plus tard pour ne pas perturber l'animation de fermeture. Un échec s'affiche dans la conversation via `actionError`, sans rouvrir le menu ni déplacer le fil.

## #100 Fonds, photos, clavier

- Fond : fil et liste sur le fond du thème (`canvas`/`surface`), `scrollContentBackground(.hidden)`, barre de navigation teintée, plus de `.background(.bar)` dans le composeur ni le pied de page.
- Clavier : seul le **fond** du composeur (Drivy) s'étend sous la zone sûre et le clavier (`ignoresSafeArea(.container/.keyboard)` sur le fond uniquement). Les arrondis et le fond propres au clavier système ne sont pas modifiés : ce qui restait noir autour venait du matériau `.bar`, retiré.
- Photos : `peerPersonId` (déjà renvoyé par l'API) est décodé dans `MessagingConversation.peerPersonID`. La cellule charge la photo du pair (`workspace.loadPhoto`) et la passe à l'avatar. Initiales seulement en repli.

## #103 Lecture, compteur, badge, notifications

- `conversationViewed(_:upTo:)` est appelé quand le bas du fil est affiché et l'app active. Borne monotone limitée au dernier message lisible chargé, une seule requête en vol par conversation. Ouvrir la liste ne marque rien.
- Après confirmation serveur seulement : compteur local recalculé, part messagerie du badge (`DrivyBadge`, sans écraser d'autres sources), retrait des seules alertes livrées de **cette école + conversation** dont la séquence est couverte. Échec serveur : rien n'est retiré.
- Charges push messagerie : `kind: MESSAGING`, `schoolId`, `conversationId`, `sequence`, `thread-id`. Les alertes de cours n'ont pas `kind` et ne sont jamais touchées.

## #101 Mentions

- iOS : taper `@` dans le général affiche les participants au-dessus du champ, `@D` filtre (casse et accents ignorés), la sélection insère `@Prénom Nom ` dans le texte sans quitter la saisie. Effacer le texte d'une mention la retire. Bouton « Mentionner » et feuille séparée supprimés.
- API : migration `20261025_messaging_mention_push.sql`. Un déclencheur met en file une alerte « Quelqu'un vous a mentionné » par personne mentionnée (hors auteur), relue avant envoi (préférence, adhésion, lien ouvert, retrait, sourdine, message non supprimé). Aucun nom d'auteur : aucune règle existante ne permet de l'exposer dans un push chiffré de bout en bout. Pas de contenu.
- Migration non déployée. Tout déploiement homelab demande sauvegarde et accord.
